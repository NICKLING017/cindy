## 打码说明

原始录屏是手机拍摄电脑屏幕，画面里包含侧边栏的任务名称、预览文案与时间戳。处理时对**任务列表区域**（含「伙伴」卡片下方的全部任务条目）做了局部高斯模糊，导航区（新建 / 自动化 / 插件 / 搜索 / 项目看板 / 更多）与窗口标题保留可读，便于定位问题。

除该区域外未对画面做任何裁剪或修改。

## 已知局限

原始素材为手持拍摄，量化下来侧边栏背景的逐帧亮度波动（7.7/255）与同屏聊天区对照（5.9/255）基本相当，**拍摄晃动与自动曝光的噪声盖过了 UI 本身的闪烁**，因此这段视频只能作为「现象存在」的佐证，不足以量化闪烁频率与幅度。
